# Phrase Bank 预置语言块设计

## 目标

为首次使用 Phrase Bank 的用户自动准备一组可立即收藏和复习的自然英语表达，避免空句库，同时允许用户以后自由编辑、删除和补充。

## 内容范围

预置 40 条中等难度、自然且高频的语言块：

- 日常沟通：24 条。
- 旅行场景：12 条。
- 聊天社交：4 条。

每条包含英文表达、中文含义、分类和贴近日常生活的个人例句。不加入来源备注。表达应适合已有一定英语基础、希望提高主动调用速度的成年用户，避免过于基础的课本句，也避免生僻俚语和高度地域化表达。

## 初始化行为

- 在本地数据库首次初始化时写入预置分类和 40 条语言块。
- 预置语言块使用固定、稳定且带 `starter-` 前缀的 ID。
- 初始化状态由独立的元数据版本 `starterPhrasesVersion` 记录，初始版本为 `1`。
- 如果应用已有数据但尚未记录预置版本，仍补充缺失的预置语言块；遇到相同 ID 时跳过，绝不覆盖现有记录。
- 成功写入或确认全部记录已存在后，才写入 `starterPhrasesVersion = 1`。
- 用户以后删除某条预置内容，初始化过程不会再次执行，因此该内容不会自动恢复。
- 用户现有语言块、分类、复习记录和复习进度均不修改。

## 复习行为

- 新写入的预置语言块将 `nextReviewAt` 设置为初始化时间，立即进入今日复习队列。
- 初始掌握等级和复习阶段均为 `0`。
- 后续复习完全使用现有的“不会、模糊、掌握”调度规则。

## 数据边界

- 预置内容是普通语言块，初始化后可以编辑、删除、导出和重新导入。
- 备份格式无需改变。
- 不增加新的界面、按钮或设置项。
- 不从网络获取内容，不引入新的权限或服务器存储。

## 异常处理

- 分类和语言块写入使用同一个数据库事务。
- 任一写入失败时不更新预置版本标记，避免留下“已完成但内容缺失”的状态。
- 下次打开应用时可以安全重试；稳定 ID 会阻止重复记录。

## 测试与验收

- 新数据库首次初始化后包含 8 个默认分类和 40 条预置语言块。
- 分类分布严格为日常 24、旅行 12、聊天社交 4。
- 所有预置记录包含非空英文、中文和个人例句，分类引用有效。
- 重复初始化不会增加记录。
- 已有相同 ID 的记录不被覆盖。
- 删除预置记录后再次打开应用不会恢复该记录。
- 已有用户记录和复习进度保持不变。
- 初始化失败时不写入版本标记，下一次可以重试。
