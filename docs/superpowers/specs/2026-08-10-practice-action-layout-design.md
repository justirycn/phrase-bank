# 训练操作区布局修复

## 目标

修复 iPhone 训练提示页中按钮层级松散、发音图标与文字分离的问题。

## 已确认布局

- 第一行是两个等宽辅助按钮：“不会，直接看答案”和“先听发音”。
- “先听发音”的扬声器图标与文字作为一个整体水平、垂直居中。
- 第二行是全宽深绿色主按钮：“查看答案并自评”。
- 所有按钮至少 44px 高，保留底部安全区；窄屏文字不被图标挤到另一侧。
- 不改变三个操作的训练语义、评分、发音或复习数据。

## 验证

- 组件测试验证辅助按钮位于同一容器，主按钮位于下一行。
- CSS 测试验证双列、主按钮配色、图标文字 flex 居中和触控高度。
- 完整测试、lint、生产构建和线上 HTTPS 健康检查必须通过。
