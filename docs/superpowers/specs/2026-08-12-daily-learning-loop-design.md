# 每日句子学习闭环设计

## 目标

把首页从“按分钟训练”改成“按句子成果推进”，删除“三分钟速练”入口，并确保新句学习与复习都能逐句保存、退出后继续。

## 首页

- 主进度显示“今日掌握 N 句”，N 按上海自然日内获得 `good` 的不同句子去重计算，不再展示 30 分钟目标。
- 同时展示“新学 N 句 · 复习 N 句”，让学习过但尚未掌握的活动也有反馈。
- 主按钮“继续今日任务”按以下优先级打开：未完成的新句学习、未完成的复习、今日待复习、新句学习。
- 保留“学习新句”和“今日复习”两个明确入口。
- 删除“三分钟速练”入口；旧 `quick` 会话与备份格式继续兼容，不迁移也不删除历史数据。

## 新句学习

- 学习阶段同时显示英文、中文、使用场景、例句和发音。
- 测试阶段先只显示中文，揭晓后显示英文并自评。
- 沿用现有 `LearningSessionRecord`，每次阶段或游标变化后持久化，刷新、退出、换设备后恢复。

## 今日复习

- 统一使用现有 `TrainingSessionRecord` 的标准训练流程，不再使用只存在组件内存中的临时复习游标。
- 提示阶段只显示中文；揭晓后显示英文，选择“不会 / 模糊 / 掌握”。
- 每次评价先保存训练事件和下一游标，再更新界面；退出或刷新后从未完成位置恢复。
- 复习完成后关闭活动会话，下一次进入创建新组。

## 数据与错误处理

- 不新增数据库版本，不改变云端快照格式。
- 首页统计直接来自已有学习状态和训练事件。
- 保存失败时不推进游标，并保留当前句供重试。
- 不修改登录、账号、云端隔离和部署配置。

## 测试

- 首页不再出现分钟目标或三分钟速练，正确显示去重后的掌握、新学、复习数量。
- “继续今日任务”的四级优先顺序有组件集成测试。
- 今日复习进入标准可恢复训练；刷新后恢复相同会话、队列和游标。
- 新句学习阶段中英文同屏，测试揭晓前只显示中文。
- 旧 `quick` 会话仍可读取，保证历史数据兼容。
