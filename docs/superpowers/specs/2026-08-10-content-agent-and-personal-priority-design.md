# Phrase Bank 内容 Agent 与个人优先训练设计

## 1. 产品目标

为 Phrase Bank 建立一套可持续的内容供给与训练系统：

- 预置约 600 个高频核心语言块，每个核心块包含 2–3 个发散案例，总量约 2000 句。
- 覆盖日常生活、旅游出行、工作沟通、商务谈判、产品与供应链、社交与情绪。
- 用户仍可使用现有单条添加功能积累自己的句子。
- 用户内容进入个人优先队列；完成个人优先阶段后，再由系统内容补充训练。
- 核心块掌握后逐步解锁案例，避免一次性把 2000 句全部推入复习队列。
- 第一阶段不依赖网页内 AI API。未来准备好 OpenAI API Key 后，再启用“让 Agent 扩展这句话”。

## 2. 已确认的产品决策

### 2.1 Agent 运行方式

采用分阶段的 C 方案：

1. 先离线生成、质检并发布系统内容包。
2. 用户在网页中继续单条添加个人句子。
3. 未来增加手动触发的 AI 扩展按钮，而不是每次添加都自动调用 AI。
4. OpenAI API Key 只保存在腾讯云服务器，不下发到浏览器。

### 2.2 内容规模

- 约 600 个核心语言块。
- 每个核心块 2–3 个发散案例。
- 总内容约 2000 句，而不是 2000 个互不关联的核心句。

### 2.3 分类配额

| 一级分类 | 核心块数量 | 典型子场景 |
| --- | ---: | --- |
| 日常生活 | 180 | 起居、饮食、购物、健康、安排、表达需求、解决小问题 |
| 旅游出行 | 100 | 机场、酒店、交通、餐厅、问路、预订、突发情况 |
| 工作沟通 | 120 | 会议、进度、协作、反馈、优先级、解释问题、做决定 |
| 商务谈判 | 100 | 询价、报价、条件、异议、协商、跟进、投诉、建立信任 |
| 产品与供应链 | 70 | 产品介绍、功能价值、MOQ、交期、质量、包装、供应商沟通 |
| 社交与情绪 | 30 | 寒暄、邀请、拒绝、赞同、边界、感受、关系维护 |

总计 600 个核心语言块。子场景必须在生成前定义明确配额，避免某些热门场景重复过多、长尾场景缺失。

### 2.4 英语风格

- 难度范围为 CEFR A2–B2。
- 高频、自然、能脱口而出的表达优先。
- 约 20% 可为稍高级的工作和商务表达。
- 使用国际通用英语，以美式拼写和表达为默认。
- 商务内容避免过度俚语、过时表达和地区性太强的说法。
- 中文必须是自然意思，不采用生硬逐字翻译。

## 3. 内容 Agent 架构

初始 Agent 是离线内容生产流水线，不在用户每次训练时调用模型。

### 3.1 内容规划器

输入：分类配额、子场景、难度、使用意图和已生成内容索引。

输出：每批待生成的内容任务。每个任务明确：

- 一级分类与子场景
- 难度
- 使用意图，例如询问、拒绝、解释、协商、确认、描述价值
- 目标语言功能与应避免的近义重复

### 3.2 核心语言块生成器

为每个任务生成核心英文、自然中文、简短使用说明和关键词。核心表达必须：

- 能独立用于真实对话
- 长度适合口语调用
- 不依赖过多上下文才能理解
- 优先复用高价值句型骨架，而不是堆砌低频词汇

### 3.3 案例扩展器

为每个核心块生成 2–3 个跨情境案例。案例应迁移同一个语言功能，而不是仅替换一个名词。案例优先覆盖不同场景，例如生活、工作和商务。

### 3.4 质量守门员

内容在自动发布前必须通过以下检查：

1. 英文语法正确。
2. 表达自然、当代且适合国际交流。
3. 中文意思准确自然。
4. 分类、子场景和使用意图一致。
5. 难度标注合理。
6. 核心块与案例之间存在明确迁移关系。
7. 与已有内容不存在高相似重复。
8. 不包含隐私数据、品牌依赖、危险建议或不适合通用学习的内容。

失败项自动返回生成器重写。内容包保留生成批次、模型版本、提示版本、质检结果和回滚版本。用户选择自动发布，不设置人工逐批审核门槛。

### 3.5 去重策略

去重分两层：

- 精确归一化：大小写、标点、缩写和空白归一后去重。
- 语义聚类：近义表达聚为一组，仅保留最自然、最高频的核心表达；有明显语气或适用场景差异时才保留多个版本。

## 4. 数据模型

### 4.1 内容来源

每条内容增加来源字段：

- `personal`：用户自己添加，可编辑、删除，默认进入个人优先队列。
- `system`：Agent 内容包提供，只读、可版本升级。

### 4.2 内容层级

系统内容分为：

- `core`：核心语言块，可直接进入训练。
- `example`：发散案例，属于一个核心块，按 `unlockOrder` 逐个解锁。

每条系统内容至少包含：

- 稳定内容 ID
- 英文
- 中文
- 一级分类、子场景
- CEFR 难度
- 使用意图
- 内容类型 `core | example`
- 父核心 ID（案例必填）
- 解锁顺序（案例必填）
- 内容包版本
- 质量检查版本

### 4.3 学习状态与内容分离

系统内容版本与用户学习状态必须分离：

- 更新英文或中文时不重置学习进度。
- 删除或下架系统内容时保留历史训练事件，但不再进入新训练。
- 内容升级不覆盖个人句子。
- 备份必须同时保存个人内容、系统内容版本、解锁状态和训练记录。

## 5. 个人句子优先逻辑

### 5.1 添加方式

第一版继续使用当前单条添加，不增加批量粘贴或 CSV 导入。

### 5.2 个人优先毕业条件

- 每天最多引入 5 条从未训练过的个人句子。
- 个人句子需要在两个不同的 Asia/Shanghai 日期分别获得一次“掌握”，才退出个人优先队列。
- 同一天重复获得“掌握”只计一次毕业日期。
- 退出个人优先队列后仍保留普通抗遗忘复习，不代表永久完成。

### 5.3 每组训练顺序

标准组与快速组使用同一优先级：

1. 到期复习项；同等到期时个人内容优先于系统内容。
2. 尚未完成个人优先阶段的内容。
3. 当天可引入的个人新句子。
4. 系统已解锁且到期的案例。
5. 系统核心新内容或新解锁案例。
6. 库存不足时，从今天已经练过的合格内容中回补。

个人内容不足时系统内容自动补满训练组。单组内点击“不会”仍只追加一次重练，禁止无限循环。

## 6. 核心块与案例解锁

- 核心块在两个不同的 Asia/Shanghai 日期获得“掌握”后，解锁第一个案例。
- 案例作为独立训练项进入系统新内容池。
- 每个核心块同一时间最多有一个尚未掌握的解锁案例。
- 当前案例达到两个不同日期的“掌握”后，才解锁下一案例。
- 系统核心与案例共享每天最多 3 个系统新训练项的额度。
- 已解锁案例继续使用普通抗遗忘曲线。

## 7. 句库界面

### 7.1 双标签页

句库分为：

- “我的句子”：默认标签页，支持当前的搜索、分类、添加、编辑和删除。
- “系统句库”：显示约 600 个核心块，支持搜索、分类、子场景和难度筛选。

### 7.2 系统核心详情

详情页显示：

- 核心英文、中文、分类、子场景、难度和使用意图
- 核心学习进度
- 已解锁案例
- 锁定案例的解锁条件
- “复制到我的句子”操作

系统内容只读。复制后生成独立的个人句子，后续系统更新不会覆盖该副本。

## 8. 未来网页 AI 扩展

该能力不阻塞第一版。启用时：

- 用户在个人句子详情点击“让 Agent 扩展这句话”。
- 浏览器只提交句子 ID 和用户请求到腾讯云后端。
- API Key 只存在服务器环境变量中。
- Agent 返回 2–3 个候选案例，用户选择后才保存为个人内容。
- 设置调用频率限制、超时、失败重试和每日预算。
- AI 失败不影响原句和训练数据。

## 9. 错误与更新策略

- 系统内容包采用先验证、后事务导入；任何一条结构不合法则整包拒绝。
- 导入失败继续使用上一个有效版本。
- 内容升级可重复执行，稳定 ID 保证幂等。
- 解锁或调度失败不得破坏现有复习记录。
- 用户可导出完整备份；恢复后应重建相同的个人优先和解锁状态。

## 10. 测试与验收

### 10.1 Agent 内容验收

- 核心块数量和分类配额准确。
- 每个核心块包含 2–3 个案例。
- 无精确重复；语义近重复低于预设阈值。
- 难度、分类、使用意图和中英一致性检查全部通过。
- 随机抽样覆盖六大分类和 A2–B2 难度。

### 10.2 产品行为验收

- 个人新句每日最多 5 条。
- 两个不同日期的“掌握”才能完成个人优先阶段。
- 个人内容不足时系统内容正确补位。
- 核心与案例按顺序解锁，不会一次性全部进入队列。
- 系统新内容每日最多 3 条。
- 快速组和标准组不返回重复 ID；库存不足时安全回补。
- 系统内容升级不覆盖个人内容或学习进度。
- 备份导入导出保持来源、层级、解锁与训练状态。

### 10.3 移动端验收

- iPhone 13 Pro 尺寸下双标签页、筛选和详情无横向溢出。
- 所有操作目标至少 44px。
- 600 个核心块列表使用分页或虚拟化，滚动和搜索无明显卡顿。
- 离线状态仍可浏览已导入内容并训练。

## 11. 分阶段实施

该项目分成三个可独立验收的子项目：

### 阶段一：内容与学习基础设施

- 扩展数据模型与 IndexedDB 迁移。
- 建立系统内容包导入、版本和回滚。
- 实现个人优先、不同日期掌握计数和案例解锁。
- 升级备份格式与兼容迁移。

### 阶段二：内容 Agent 与系统句库

- 定义子场景配额和结构化生成协议。
- 生成并质检约 600 个核心块和约 2000 句总内容。
- 实现“我的句子 / 系统句库”、筛选、详情与复制。
- 发布首个内容包。

### 阶段三：网页手动 AI 扩展

- 腾讯云后端代理 OpenAI API。
- 实现手动扩展、候选预览、选择保存、限流与预算。
- 该阶段仅在用户准备好 API Key 后启动。

阶段一必须先完成；阶段二依赖阶段一；阶段三不阻塞前两阶段。
