# Phrase Bank 固定账号与云端进度设计

## 目标与范围

为 Phrase Bank 增加一个适合 2–3 人使用的轻量登录系统，防止陌生人直接访问或滥用。账号由管理员预先创建，不开放注册、找回密码或网页端账号管理。

登录后，每个账号拥有独立的个人句子、学习状态、复习记录、训练记录、学习会话和语音设置。系统内置句库对所有账号共享。本机 IndexedDB 中已有的数据不迁移、不上传；上线后以云端数据为准，从新的账号空间开始使用。

## 方案

应用继续部署在现有腾讯云服务器和域名 `phrase.archdemy.com`，服务端新增一个持久化 SQLite 数据库。浏览器通过同域 HTTPS 接口登录和读写数据，不接入第三方身份服务。

服务器提供一个仅能在服务器命令行运行的账号管理脚本。管理员输入自定义用户名和密码创建账号，也可以停用账号或重设密码。密码允许由管理员自行决定复杂度，但服务器只保存带随机盐的密码哈希，不保存明文密码。

## 登录体验

- 未登录访问任何应用页面时，只显示极简登录页。
- 登录页包含账号、密码、登录按钮和统一错误提示，不提供注册入口。
- 登录成功后进入首页；同一设备保持登录 30 天。
- 设置页增加“退出登录”，退出后立即删除会话并返回登录页。
- 账号被停用、会话过期或服务端返回未授权时，客户端清除当前会话并回到登录页。
- 登录失败只显示“账号或密码错误”，不泄露账号是否存在。
- 同一来源连续失败会受到短时限流，成功登录后清除该来源的失败计数。

## 会话与安全

- 会话使用随机、不可预测的令牌；SQLite 只保存令牌摘要。
- Cookie 设置 `HttpOnly`、`Secure`、`SameSite=Lax`、限定站点路径，并设置 30 天有效期。
- 所有数据接口都从服务端会话解析 `userId`，不接受客户端自行提交用户 ID。
- 修改类接口检查同源请求，限制 JSON 请求体大小，并对输入执行现有领域校验。
- 密码使用 Node 加密模块提供的 `scrypt` 加随机盐哈希。
- Caddy 继续负责 HTTPS；旧 IP 的 HTTP 入口不再允许绕过登录访问数据。

## 数据模型

SQLite 保存以下逻辑表：

- `users`：账号、密码哈希、盐、启用状态、创建和更新时间。
- `sessions`：用户、会话令牌摘要、过期时间、创建和最后使用时间。
- 用户数据表：个人句子、个人分类、学习状态、复习日志、训练事件、训练会话、学习会话和语音设置，全部带 `user_id`。
- 服务端元数据：数据库版本、当前活动训练会话和当前活动学习会话，按用户保存。

系统内置句子仍由已发布的内容包提供并共享；用户对系统句子的学习状态和训练记录写入自己的云端空间。个人句子只对创建它的用户可见。

所有唯一键和查询都包含 `user_id`。复习评分、首次学习评分、完成会话等现有原子操作继续在一个 SQLite 事务中完成，防止只保存了一半进度。

## 客户端与接口边界

新增服务端 API，分为：

- 身份接口：登录、查询当前会话、退出。
- 数据接口：按现有 `PhraseRepository` 能力提供读取、保存、删除和原子评分操作。

客户端新增 `CloudPhraseRepository`，实现现有 `PhraseRepository` 接口并调用同域 API。登录成功后，`PhraseBankApp` 只使用云端仓储；不会读取或合并旧的 `LocalPhraseRepository` 数据。现有训练、学习、热力图和句库组件无需了解账号信息。

为减少首页请求，首页所需数据继续使用有界读取；服务端按账号查询并返回，不传输其他账号的数据。接口错误维持现有可恢复提示，401 则统一交给登录边界处理。

## 部署与运维

- Compose 为应用挂载独立持久化目录保存 SQLite 文件；重新构建容器不会删除数据库。
- 数据库启动时执行幂等迁移；部署前后均可重复运行。
- 首批账号在服务器命令行创建，命令交互式读取密码，避免密码出现在 shell 历史和 GitHub Actions 日志中。
- 提供备份说明：停止写入或使用 SQLite 在线备份后复制数据库文件；恢复前保留旧文件。
- 不把账号密码、会话密钥或数据库文件提交到 Git。

## 错误处理

- SQLite 暂时不可用：登录页或应用显示通用可重试提示，不泄露路径和 SQL。
- 数据写入失败：事务回滚，客户端保留当前操作供重试。
- 会话过期：返回 401，客户端回到登录页，不误显示其他账号或旧本地数据。
- 同名账号创建：管理命令明确拒绝，不覆盖已有账号。
- 停用账号：现有会话全部失效，数据保留以便恢复。

## 测试与验收

- 密码哈希、登录成功/失败、30 天会话、退出、停用和限流测试。
- 未登录不能读取或修改任何用户数据。
- 两个账号写入同 ID 的个人句子和进度后，读取结果完全隔离。
- 系统句库双方可见，但学习状态互不影响。
- 原子评分失败时，句子、事件、状态和会话均不发生部分更新。
- 客户端首次打开显示登录页；登录后进入首页；401 回到登录页；退出后受保护内容消失。
- 验证登录后不读取或上传旧 IndexedDB 数据。
- 验证 SQLite 数据卷在容器重建后仍保留。
- 全量测试、构建、部署健康检查和公网 HTTPS 登录流程通过后发布。

## 明确不做

- 自助注册、邮箱、短信、验证码、第三方登录和找回密码。
- 网页端账号管理后台和多角色权限。
- 旧本地数据迁移、合并或自动上传。
- 多设备离线编辑与冲突合并；离线时只提示网络不可用。
