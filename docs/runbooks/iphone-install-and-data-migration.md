# Phrase Bank：迁移到 iPhone 桌面

请在同一台 iPhone 上按以下顺序操作。

## 1. 迁移前从旧地址导出

1. 用 Safari 打开旧地址：<http://43.153.204.17>。
2. 依次进入“设置”→“数据备份”→“导出备份”。
3. 将导出的 JSON 备份文件保存到“文件”App。

迁移期间不要清除 Safari 网站数据。旧地址的数据仍需保留，以便在新域名无法使用时回退。

## 2. 在新域名导入

1. 用 Safari 打开新域名：<https://phrase.archdemy.com>。
2. 确认页面打开时没有安全警告；如果出现安全警告，请停止导入并按下方“回退”操作。
3. 先确认旧地址是唯一真实的数据来源，而且新域名尚未正式使用。如果旧地址不是唯一真实的数据来源，或者新域名已经正式使用并且需要合并其中的数据，请立即停止本次迁移，不要导入，并按下方“回退”操作。本流程不提供数据合并。
4. 如果新域名中已有测试、收藏、训练或任何数据，请先在新域名依次进入“设置”→“数据备份”→“导出备份”，另存一个独立的 JSON 备份文件。不要与旧地址导出的 JSON 混淆。如果其中的数据需要合并或保留在迁移结果中，请按上一步停止迁移。
5. 确认“旧地址是唯一真实的数据来源”“新域名尚未正式使用”，并且新域名如有数据已完成独立备份后，依次进入“设置”→“数据备份”→“导入备份”，选择刚才从旧地址保存到“文件”App 的 JSON 备份文件。
6. 覆盖会用旧备份替换新域名中所有相同 ID 的分类、语言块、复习记录和训练记录。
7. 当页面提示“遇到重复记录时，用备份中的内容覆盖吗？”时，必须点“好”或“确定”执行覆盖。点“取消”会跳过重复项，可能造成迁移不完整，因此本迁移流程不要点“取消”。
8. 等待页面显示导入成功提示后，再继续操作。
9. 核对分类数量和语言块数量是否与旧地址一致。
10. 开始一次快速训练，确认训练进度能够保存。

## 3. 添加到主屏幕

1. 停留在 Safari 的新域名页面，点“分享”。
2. 点“添加到主屏幕”。
3. 名称保留为“Phrase Bank”，然后点“添加”。
4. 从 iPhone 桌面点 Phrase Bank 图标启动。
5. 确认打开后没有 Safari 地址栏。
6. 第一次开始训练时，按提示允许使用麦克风。

## 4. 回退

如果出现以下任一情况：新域名无法打开、导入失败、分类或语言块数量不一致、训练进度无法保存，或从桌面图标启动异常，请立即停止在新域名新增内容或训练，并用 Safari 回到旧地址：<http://43.153.204.17>。

- 不要清除或删除旧地址、新域名任一方的 Safari 网站数据。
- 保留旧地址导出的 JSON 备份文件；如果已经为新域名导出备份，也要一并保留。
- 记录页面显示的提示内容，以便后续排查。
