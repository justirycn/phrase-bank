# Phrase Bank：迁移到 iPhone 桌面

请在同一台 iPhone 上按以下顺序操作。

## 1. 迁移前从旧地址导出

1. 用 Safari 打开旧地址：<http://43.153.204.17>。
2. 依次进入“设置”→“数据备份”→“导出备份”。
3. 将导出的 JSON 备份文件保存到“文件”App。

迁移期间不要清除 Safari 网站数据。旧地址的数据仍需保留，以便在新域名无法使用时回退。

## 2. 在新域名导入

1. 用 Safari 打开新域名：<https://phrase.archdemy.com>。
2. 确认页面打开时没有安全警告；如果出现安全警告，请停止导入并按下方“回退”操作。
3. 依次进入“设置”→“数据备份”→“导入备份”，选择刚才保存到“文件”App 的 JSON 备份文件。
4. 出现重复记录处理选项时，选择“覆盖重复记录”。
5. 等待页面显示导入成功提示后，再继续操作。
6. 核对分类数量和语言块数量是否与旧地址一致。
7. 开始一次快速训练，确认训练进度能够保存。

## 3. 添加到主屏幕

1. 停留在 Safari 的新域名页面，点“分享”。
2. 点“添加到主屏幕”。
3. 名称保留为“Phrase Bank”，然后点“添加”。
4. 从 iPhone 桌面点 Phrase Bank 图标启动。
5. 确认打开后没有 Safari 地址栏。
6. 第一次开始训练时，按提示允许使用麦克风。

## 4. 回退

如果新域名无法打开或导入失败，请用 Safari 回到旧地址：<http://43.153.204.17>。

- 不要删除旧网址的网站数据。
- 保留导出的 JSON 备份文件。
- 记录页面显示的提示内容，以便后续排查。
